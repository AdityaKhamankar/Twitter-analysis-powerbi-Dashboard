How it was built

Workflow & Tools

The project uses data transformation, calculated columns, DAX measures, and visual analysis.

01 · Prepare Data CSV input and data cleaning using Power Query.
02 · Transform Date formatting and extraction of month, quarter, day, and hour, plus character and word counts.
03 · Model & Calculate DAX measures and calculated columns for engagement and time-based visibility.
04 · Visualize Compare tweet categories, interactions, media activity, and monthly trends in Power BI.
