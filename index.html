Project Workflow

Methodology & Tools

The workflow combines data preparation, transformation, DAX calculations, and visualization.

01. Data Preparation

Use the CSV dataset as the source for the analytics project.

02. Data Transformation

Clean and transform data using Power Query. Extract date parts and text characteristics.

03. DAX Calculations

Create measures and calculated columns for engagement and time-based analysis.

04. Visualization

Build charts to compare tweet performance, interaction totals, and engagement trends.
