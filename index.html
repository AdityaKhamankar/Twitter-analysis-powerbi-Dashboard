Twitter Analytics Dashboard

Social Media Engagement Analysis using Microsoft Power BI

Project by Aditya Khamankar

About the Project

This project uses Microsoft Power BI to analyze Twitter engagement data. It includes data cleaning, transformation, DAX calculations and interactive visualizations to explore tweet performance and engagement patterns.

Project Objectives

  • Analyze tweet interactions by category.
  • Compare engagement rates with and without app opens.
  • Examine media views and engagements by weekday.
  • Compare replies, retweets and likes.
  • Explore monthly engagement rate trends.
  • Identify tweets with high total engagement.

Dashboard Tasks

01. Tweet Interaction Breakdown

Compare profile clicks, hashtag clicks and URL clicks by tweet category.

02. Engagement Rate Comparison

Compare engagement rates based on app-open activity.

03. Media Interaction by Weekday

Explore media views and engagements across days of the week.

04. Tweet Performance

Compare replies, retweets and likes.

05. Monthly Engagement Trends

Examine monthly engagement rates for tweets with and without media.

06. Top Tweets

Identify tweets with the highest total engagement.

Tools and Technologies

Microsoft Power BI · Power Query · DAX · Data Cleaning · Data Transformation · Data Visualization
